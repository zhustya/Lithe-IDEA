Lithe Desktop 0.8.16 带来远程开发、更完整的编辑器提示与 Git 操作，同时保留个人 fork 的 SourceGit 风格提交图、搜索索引设置和提交菜单复制分支名称。

### 重点更新

本次把上游 0.8.11 至 0.8.19 的改动并入 fork，并保留 fork 原有的界面与更新方式。

#### ✨ 新功能

- 远程开发支持 SSH、WSL 与容器连接，可在远端打开项目、搜索文件、运行配置并转发端口。
- 编辑器新增内置彩虹配色、缩进参考线和上下文高亮，参数与返回值提示仍保持原有样式。
- 编辑器支持插件叠加文本前景色、双向实现跳转与 gutter 图标，并可开关自动补全。
- 新增可信位置设置，构建选项会标明是对工作区还是全局生效。
- Git 日志的提交右键菜单新增“复制分支名称”，右键带分支标签的提交即可复制分支名。

#### ⚡ 改进

- 省略号截断的文字悬停时显示全文，长提交说明和文件名不再需要点开才知道内容。
- 关闭窗口时记住尺寸与最大化状态，下次打开保持一致。
- 运行会话按插件聚合，树形详情可折叠，控制台可横向滚动。
- 插件设置与运行视图减少每帧开销，插件支持增量更新与后台暂存。
- 搜索结果复制文案修正英文复数，虚拟列表定位到屏外行后首帧即可见。

#### 🛠 修复

- 修复强制删除分支缺少二次确认、多选结果异常和中文“暂存”文案混淆的问题。
- 修复删除分支后工作台短暂无响应的问题，以及最近项目菜单读取 HEAD 太慢的问题。
- 修复部分工具链发现失败被静默吞掉、配置读取失败没有日志的问题。
- 修复搜索结果跳转后目标行落在视口边缘的问题（fork 原有改进保留）。

### 升级说明

- 已安装 0.8.12 或之后的个人 fork 版本，可在标题栏更新入口或“设置 → 更新”检查更新，应用会从 fork 的签名 feed 下载 0.8.16。
- 也可以直接下载安装包覆盖安装；设置、项目状态和日志仍在 `%APPDATA%\Lithe Desktop`。
- 安装包未签名，Windows 可能提示未知发布者。

### 兼容性与已知问题

- 本次仅提供 Windows x64 安装包，更新 feed 只覆盖个人 fork 的版本。
- 上游远程开发的完整原生验收仍在进行，部分远端工作流在 Windows 上尚未实机验证。
- 打开项目时默认在后台建立全文索引，可在“设置 → 工具 → 搜索 → 搜索索引”改为首次查询时建立；大型工作区首次建索引会占用一定内存和读盘时间。
- 如果 macOS 提示无法打开 Lithe.app，请在“应用程序”中按住 Control 点按应用并选择“打开”；如果仍被阻止，可在终端执行 `xattr -dr com.apple.quarantine /Applications/Lithe.app`。仅对可信来源的应用使用。

## English

Lithe Desktop 0.8.16 brings remote development, richer editor hints and Git fixes, while keeping the fork's SourceGit-style commit graph, search-index setting and Copy Branch Name action.

### Highlights

This release merges upstream 0.8.11–0.8.19 into the fork and keeps the fork's own UI and update channel.

#### ✨ New features

- Remote development supports SSH, WSL and containers, with projects, search, run configurations and port forwarding on the host.
- The editor gains built-in rainbow colors, indent guides and context highlighting; inlay hints keep their existing style.
- Plugin text foreground, bidirectional implementation navigation and gutter icons are available, and autocomplete can be toggled.
- Trusted Locations settings and workspace-scope labels on build options make tool behavior clearer.
- The Git log commit menu gains Copy Branch Name: right-click a commit with branch labels to copy them.

#### ⚡ Improvements

- Hovering truncated text shows the full subject or filename.
- Window size and maximized state are restored on the next launch.
- Run sessions are grouped by plugin, tree details fold, and the console scrolls horizontally.
- Plugin settings and run views do less work per frame; plugins support incremental updates and background staging.
- Search count wording is number-neutral in English, and off-screen list targets are visible on the first frame.

#### 🛠 Fixes

- Force-delete now asks for confirmation, multi-select results are corrected, and the Chinese Stash copy no longer reads as staging.
- Deleting a branch no longer leaves the workbench briefly unresponsive, and the recent-project menu reads HEAD metadata faster.
- Partial toolchain discovery failures and unreadable settings are now logged instead of being silently dropped.
- Search-result jumps reveal the target line in the middle of the editor, a fork improvement retained in this release.

### Upgrade instructions

- On 0.8.12 or a later fork build, use the title bar update entry or Settings → Updates; the app downloads 0.8.16 from the signed fork feed.
- Or install the package over the existing app. Settings, project state, and logs stay in `%APPDATA%\Lithe Desktop`.
- The installer is unsigned, so Windows may warn about an unknown publisher.

### Compatibility and known issues

- This release ships a Windows x64 package only, and the update feed covers only this fork's releases.
- Native verification of upstream remote-development workflows is still in progress; some remote flows are not yet verified on Windows.
- The full-text index is built in the background when a project opens; turn this off under Settings → Tools → Search → Search index to build it on first search instead. Large workspaces take time and memory for the first build.
- If macOS says it cannot open Lithe.app, Control-click it in Applications and choose Open. If it is still blocked, run `xattr -dr com.apple.quarantine /Applications/Lithe.app` in Terminal. Use this only for an app from a source you trust.
