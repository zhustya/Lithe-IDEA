Lithe Desktop 0.8.11 个人预览版重做 Git Log 的提交列表与提交图，让分支、标签和提交信息更清楚。

### 重点更新

本次更新集中在 Git Log 的阅读体验，以及分支图的清晰度。

#### ✨ 新功能

- Git Log 提交行按图与引用、主题、作者头像、短 SHA、作者时间分列，并新增列标题。
- 每条分支从分叉到结束独占一列，分支结束后列才被后续分叉复用。

#### ⚡ 改进

- 引用标签改为描边标签，标签和分支名称优先完整显示，窄面板依次收起时间、SHA、作者列。
- 提交图使用 SourceGit 的十色调色板、12 点 lane 间距、2 点线宽和圆点画法。
- 换道线改为平滑贝塞尔曲线，不再出现折线折角，分支走向更容易跟随。
- 非当前分支的提交淡化显示，当前 HEAD 所在行加粗，深浅色主题都使用同一套规则。

#### 🛠 修复

- 修复长标签、长分支名和最后几个字符被标签边框裁掉的问题。
- 修复窄面板中列标题与实际列不一致的问题。

- 设置、项目状态和日志保存在 `%APPDATA%\Lithe Desktop`，升级不会清除。
- 这是未签名预览包，Windows 可能显示安全提示；它没有接入更新通道，不会自动更新。

### 兼容性与已知问题

- 本次只提供 Windows x64 预览包；版本显示为 0.8.11 Preview。
- 安装包未签名，系统可能提示未知发布者；请只从可信来源下载。

## English

Lithe Desktop 0.8.11 is a personal preview that reworks the Git Log commit list and graph so branches, tags, and commit details are easier to read.

### Downloads

- [Project homepage](https://github.com/zhustya/Lithe-IDEA)
- [Windows x64 installer](https://github.com/zhustya/Lithe-IDEA/releases/download/sourcegit-style-0.8.11/lithe-0.8.11-windows-amd64-setup.exe)
- [Windows x64 archive](https://github.com/zhustya/Lithe-IDEA/releases/download/sourcegit-style-0.8.11/lithe-0.8.11-windows-amd64.zip)
- [All downloads and SHA-256 checksums](https://github.com/zhustya/Lithe-IDEA/releases/tag/sourcegit-style-0.8.11)

### Highlights

This preview focuses on reading history in the Git Log and following the branch graph.

#### ✨ New features

- Git Log rows now separate the graph and references, subject, author avatar, short SHA, and author time under column headers.
- Each branch keeps its own column from its fork until it ends; later forks reuse a column only after it is released.

#### ⚡ Improvements

- Reference labels use outlined chips and keep tag or branch names visible; narrow panels collapse the time, SHA, and author columns in that order.
- The graph uses SourceGit's ten-color palette, 12-point lane spacing, 2-point lines, and dot style.
- Lane changes are smooth Bezier curves instead of sharp polylines, so branch directions are easier to follow.
- Commits outside the checked-out branch are dimmed and the HEAD row is bold in both themes.

#### 🛠 Fixes

- Fixed long tags, long branch names, and trailing characters being clipped by the chip border.
- Fixed the column headers not matching the columns painted in a narrow panel.

### Upgrade instructions

- Quit the running Lithe Desktop and run `lithe-0.8.11-windows-amd64-setup.exe` to install over the existing app, or extract the zip and replace the existing `lithe.exe`.
- Settings, project state, and logs stay in `%APPDATA%\Lithe Desktop` and are not removed by the update.
- This is an unsigned preview package. Windows may show a security prompt, and the package has no update channel, so it does not update itself.

### Compatibility and known issues

- This preview is Windows x64 only and shows version 0.8.11 Preview.
- The installer is unsigned, so Windows may warn about an unknown publisher; download it only from a trusted source.
- The stable-column Core change is on a fork branch and is not merged upstream yet; official auto-updates still follow official releases.
- To return to the official build, install the official 0.8.10 or newer release.
