Lithe Desktop 0.8.13 改进了编辑器里的内联参数提示，并沿用 0.8.12 的 fork 签名更新源。

### 下载

- [项目主页](https://github.com/zhustya/Lithe-IDEA)

### 重点更新

本次更新让参数提示安静下来，不再在代码里显示一块块带边框的底色。

#### ✨ 新功能

- 暂无新增功能。

#### ⚡ 改进

- 内联参数提示改为与行号一致的灰色小字，去掉底色和上下描边，代码保持连续。
- 提示仍保留点击插入参数的提示框和插入行为；明暗主题使用同一规则。
- 继续使用 fork 的签名更新源，0.8.12 及之后的版本可以在应用内更新。

#### 🛠 修复

- 修复参数提示的矩形底色在部分深色主题下过于显眼、遮挡代码节奏的问题。

### 升级说明

- 已安装 0.8.12 的用户可在标题栏更新入口或“设置 → 更新”检查更新，应用会从 fork 的签名 feed 下载 0.8.13。
- 也可以直接下载安装包覆盖安装；设置、项目状态和日志仍在 `%APPDATA%\Lithe Desktop`。
- 安装包未签名，Windows 可能提示未知发布者。

### 兼容性与已知问题

- 本次仅提供 Windows x64 安装包。
- 更新 feed 位于 `https://github.com/zhustya/Lithe-IDEA/releases/download/desktop-update-feed/stable.json`，只覆盖个人 fork 的版本。
- 内联提示的颜色取自编辑器主题的次级文字色；如果自定义主题的该颜色过淡，提示会相应变淡。

## English

Lithe Desktop 0.8.13 refines inline parameter hints and keeps the fork's signed update feed from 0.8.12.

### Downloads

- [Project homepage](https://github.com/zhustya/Lithe-IDEA)
- [Windows x64 installer](https://github.com/zhustya/Lithe-IDEA/releases/download/sourcegit-style-0.8.13/lithe-0.8.13-windows-amd64-setup.exe)
- [Windows x64 archive](https://github.com/zhustya/Lithe-IDEA/releases/download/sourcegit-style-0.8.13/lithe-0.8.13-windows-amd64.zip)
- [All downloads and SHA-256 checksums](https://github.com/zhustya/Lithe-IDEA/releases/tag/sourcegit-style-0.8.13)

### Highlights

This release quiets parameter hints so they no longer break the code with bordered background boxes.

#### ✨ New features

- None.

#### ⚡ Improvements

- Inline parameter hints now use the muted line-number color at a smaller size, with no background or top and bottom borders.
- Hints keep their click-to-insert tooltip and action, and both themes follow the same rule.
- The fork's signed update feed continues from 0.8.12, so later builds can update inside the app.

#### 🛠 Fixes

- Fixed the rectangular hint background becoming too prominent in some dark themes and breaking the reading rhythm.

### Upgrade instructions

- On 0.8.12, use the title bar update entry or Settings → Updates; the app downloads 0.8.13 from the signed fork feed.
- Or install the package over the existing app. Settings, project state, and logs stay in `%APPDATA%\Lithe Desktop`.
- The installer is unsigned, so Windows may warn about an unknown publisher.

### Compatibility and known issues

- This release ships a Windows x64 package only.
- The update feed at `https://github.com/zhustya/Lithe-IDEA/releases/download/desktop-update-feed/stable.json` covers only this fork's releases.
- Hint text uses the editor theme's muted color; a custom theme with a very faint color makes hints fainter too.
