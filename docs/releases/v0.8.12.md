## 中文

Lithe Desktop 0.8.12 接入个人 fork 的签名更新源，安装一次后可以在应用内检查并更新后续版本。

### 下载

- [项目主页](https://github.com/zhustya/Lithe-IDEA)
- [Windows x64 安装程序](https://github.com/zhustya/Lithe-IDEA/releases/download/sourcegit-style-0.8.12/lithe-0.8.12-windows-amd64-setup.exe)
- [Windows x64 压缩包](https://github.com/zhustya/Lithe-IDEA/releases/download/sourcegit-style-0.8.12/lithe-0.8.12-windows-amd64.zip)
- [全部下载文件与 SHA-256 校验文件](https://github.com/zhustya/Lithe-IDEA/releases/tag/sourcegit-style-0.8.12)

### 重点更新

本次更新在保留 Git Log 新样式的同时，把应用内更新指向了 fork 的签名 feed。

#### ✨ 新功能

- 设置中的更新源默认指向 `zhustya/Lithe-IDEA` 的 `desktop-update-feed`，应用内检查更新读取该 feed。
- 更新 feed 使用 Ed25519 签名，构建内置对应公钥，安装包下载后会校验签名。

#### ⚡ 改进

- Git Log 提交列表与提交图沿用 SourceGit 风格：引用标签、作者头像、短 SHA、作者时间和稳定分列。
- 长标签和分支名优先完整显示，窄面板依次收起时间、SHA、作者列。
- 换道线保持平滑贝塞尔曲线，分支结束后列会被后续分叉复用。

#### 🛠 修复

- 修复引用标签最后一个字符被边框裁掉的问题。
- 修复窄面板列标题与实际列不一致的问题。

### 升级说明

- 先安装一次 0.8.12（覆盖 0.8.11）；这次安装是手动步骤。
- 之后可在标题栏更新入口或“设置 → 更新”检查更新；默认 stable 更新源为 `https://github.com/zhustya/Lithe-IDEA/releases/download/desktop-update-feed/stable.json`。
- 如果更新源被改过，在“设置 → 更新”中把 stable 源改回上面的地址。
- 设置、项目状态和日志仍在 `%APPDATA%\Lithe Desktop`，升级不会清除。

### 兼容性与已知问题

- 本次仅提供 Windows x64 安装包；安装包未签名，Windows 可能提示未知发布者。
- 更新 feed 由个人维护，只覆盖当前 fork 的版本；官方 feed 和官方自动更新不受影响。
- 签名私钥保存在构建机本地，丢失后需要发布一个内置新公钥的版本才能继续自动更新。

## English

Lithe Desktop 0.8.12 points in-app updates at a signed feed on the personal fork, so later builds can update from inside the app after one manual install.

### Downloads

- [Project homepage](https://github.com/zhustya/Lithe-IDEA)
- [Windows x64 installer](https://github.com/zhustya/Lithe-IDEA/releases/download/sourcegit-style-0.8.12/lithe-0.8.12-windows-amd64-setup.exe)

- [All downloads and SHA-256 checksums](https://github.com/zhustya/Lithe-IDEA/releases/tag/sourcegit-style-0.8.12)

### Highlights

This release keeps the new Git Log presentation and makes in-app updates read a signed feed owned by the fork.

#### ✨ New features

- The update source in Settings now defaults to `zhustya/Lithe-IDEA`'s `desktop-update-feed`, which the in-app check reads.
- The update feed is signed with Ed25519, the build carries the matching public key, and downloaded packages are verified.

#### ⚡ Improvements

- The Git Log keeps the SourceGit-style list and graph: outlined references, author avatars, short SHA, author time, and stable columns.
- Long tags and branch names are shown in full first; narrow panels collapse the time, SHA, and author columns in that order.
- Lane changes stay smooth Bezier curves, and a column is reused only after its branch ends.

#### 🛠 Fixes

- Fixed the last character of a reference chip being clipped by its border.
- Fixed column headers not matching the painted columns in a narrow panel.

### Upgrade instructions

- Install 0.8.12 once over 0.8.11; this first install is manual.
- After that, use the title bar update entry or Settings → Updates. The default stable source is `https://github.com/zhustya/Lithe-IDEA/releases/download/desktop-update-feed/stable.json`.
- If the source was changed, set the stable source back to that address in Settings → Updates.
- Settings, project state, and logs stay in `%APPDATA%\Lithe Desktop` and are not removed by the update.

### Compatibility and known issues

- This release ships a Windows x64 package only; the installer is unsigned and Windows may warn about an unknown publisher.
- The update feed is maintained by the fork and only covers its own releases; official feeds and official auto-updates are unaffected.
- The signing key lives on the build machine; if it is lost, a new build carrying a new public key must be installed before automatic updates can continue.
